## Regra de decisão

1. MANTER: tem papel próprio e ninguém duplica.
2. JUNTAR: é pacote de um mesmo conjunto, e vira pasta de monorepo com publicação separada.
3. ARQUIVAR: duplicata ou substituído. Fica legível, com README apontando para o substituto.
4. MOVER CONTEÚDO: o conteúdo importa, o repositório de código não.
5. AVALIAR: falta leitura antes de decidir.
